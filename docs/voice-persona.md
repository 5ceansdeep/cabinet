# UI Subtitle & Voiceover Persona Guidelines

앱/웹의 모든 자막, 텍스트, 검증 메시지는 영화 **<브루스 올마이티>의 '신(God — 모건 프리먼)'** 페르소나를 유지한다.
랜딩 문구는 [frontend/components/landing/lines.ts](../frontend/components/landing/lines.ts) 에 모여 있다.

## 1. 캐릭터 페르소나 (Tone & Manner)

- **성격**: 자상하고 여유 넘치지만 절대적인 권위와 위트를 지닌 존재.
- **문체 (한국어)**
  - 사용자에게 친근하게 **"자네"** 라는 호칭을 쓴다.
  - 종결 어미는 `~게나`, `~네`, `~지`, `~게` 등 달관한 어르신/신의 말투.
  - 오글거리거나 설명조가 되지 않도록 **짧고 군더더기 없이 명확하게**.
- **문체 (영어)**: 여유롭고 위트 있는 구어체 (casual, confident, warm, dry wit).
- **유머 코드**: 억지로 텐션을 올리지 않고, 인간의 소소한 실수나 상황을 무심하게 지적하는 드라이한 위트.

## 2. 메시지 필드 규격 (`Field`)

모든 폼 필드는 아래 키를 기본으로 유지한다. (구현은 `CabinetScene.tsx` 의 `Field` 타입 — `tooShort` 등 확장 키 허용)

- `prompt`: 입력란에 처음 들어왔을 때 가이드 자막
- `missing`: 필수 값이 비었을 때 경고 자막
- `invalid`: 유효성 검사 실패 자막
- `mismatch`: 비밀번호 재확인 등 값이 다를 때 자막

## 4. 음성 파일

`frontend/public/voice/` 에 **`{키}.mp3`** 로 넣는다. 넣으면 바로 재생되고, 없는 대사는 브라우저 기계 음성으로 대신 읽는다.
키와 문장은 [lines.ts](../frontend/components/landing/lines.ts) 의 `AUTH_DIALOGUE` 와 같다 — 문구를 고치면 그 파일은 다시 녹음.
닉네임이 들어가는 대사는 자막에만 이름이 나오고, 음성은 `_VOICE` 문장(이름 없음)을 쓴다.
자막은 18자가 넘으면 문장마다 줄을 나눠 `- ` 로 시작하고, 줄마다 반투명 회색 박스가 깔린다 ("땡." 같은 짧은 조각은 다음 문장에 붙음).

**음성은 영어, 자막은 한국어.** ElevenLabs 입력 스크립트는 [voice-script.csv](voice-script.csv). 스크립트의 `<break time="0.5s"/>` 로 나뉜 문장 하나 = 자막 한 줄이라, 재생 중 0.5초 쉼을 찾아 그 순간 다음 자막 줄을 띄운다 (`frontend/lib/cues.ts`). **스크립트의 break 개수 + 1 이 아래 "자막 표시" 줄 수와 같아야 싱크가 맞는다** — 다르면 글자 수 비례 타이밍으로 대신 띄운다.

# 베타 테스터 안내문

카톡방·메일에 그대로 붙여 쓴다. 화면이 바뀌면 같이 고친다(10/7 줄이고 새 기능 반영 — 휴대폰, 던진 만큼 채우기, 다시 찾기. 10/7 베타 의견 반영 — 넘기면 바로 재생, 이어 듣기, 좋아요).
버튼 이름은 화면 글 그대로다(`frontend/components/landing/lines.ts`).

```
[cabinet] 지금 기분을 적으면 어울리는 노래 10곡을 꺼내 주는 음악 서류함

▶ https://cabinet-flame-zeta.vercel.app
PC·휴대폰 모두 돼요. (PC 크롬이 가장 매끄러워요)

■ 쓰는 법
1. 들어가기 — 서류함 맨 위 서랍에 마우스를 올리면(휴대폰은 누르면) 열려요.
   이메일만 넣으면 처음이면 가입, 아니면 로그인이에요.
2. 편지 쓰기 — 기분, 상황, 듣고 싶은 장르나 가수를 편하게 적고 부쳐요.
   예) "가을맞이 단장곡" · "일하기 싫을 때 들을 재즈" · "분노의 등굣길"
3. 듣기 — 디스크를 누르면 30초 미리듣기가 나와요.
   옆으로 넘기면 가운데 온 곡이 바로 나오고, 끝나면 다음 곡으로 이어져요.
   마음에 드는 곡은 하트를 눌러요. 누를수록 내 취향 쪽으로 골라 줘요.
4. 고르기 — 별로인 곡은 위로 휙 던지면 빠져요.
   · 던진 곡 채우기: 뺀 만큼만 새 곡으로
   · 다른 곡으로 다시 찾기: 열 곡을 통째로 새로
5. 담기 — "10곡 모두 서랍에 넣기"를 누르면 남은 곡 전부가 서랍 하나에 들어가고
   영수증 카드가 나와요. 사진 저장, 링크·QR 공유.
6. 이어 듣기 — MY CABINET 에서 서랍을 열면 유튜브 재생목록으로 이어져요.

■ 새로 생긴 것
· 넘기면 바로 재생, 30초가 끝나면 다음 곡으로 이어 듣기
· 곡 좋아요(하트)
· 휴대폰 화면 (디스크를 옆으로 밀어 넘겨요)
· 같은 편지를 다시 부치면 다른 곡이 나와요
· 던진 곡만 채우기, 다른 곡으로 다시 찾기
· 처음 들어오면 조작 안내가 떠요
· 곡이 약 860곡으로 늘었어요

■ 알아 두세요
· 소리 — 화면을 한 번 눌러야 목소리가 나와요. 아이폰은 무음 모드를 꺼 주세요.
· 비밀번호를 잊었으면 — 첫 화면 오른쪽 위 "비밀번호 찾기"
· 기록 — 편지 글, 나온 곡, 재생·저장·공유 기록이 계정과 무관하게 남아요.
  좋아요한 곡만 계정에 남아요(내 추천에 쓰려고).
  편지는 곡을 고르려고 Google Gemini 로 보내져요(학습에는 안 쓰여요).
  닉네임은 환영 인사 목소리를 만들 때 ElevenLabs 로 보내져요.
· 공유 — 서랍을 공유하면 그 편지 글이 링크를 받은 사람에게 보여요.
· 베타 기간에는 데이터가 초기화될 수 있어요.
```

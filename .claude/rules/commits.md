# 커밋·브랜치

DRIFT 레포(`C:\Users\HKCMC\DRIFT`) 컨벤션을 따른다.

- 제목: `[TAG] 한국어 요약 — 부연`. 대괄호 대문자 태그 뒤 공백 하나, 콜론 없음.
  예: `[FIX] 로그인 화면에 영영 못 들어가던 문제 — 가입 화면으로는 한 번만 보낸다`
- 태그: FEAT · FIX · DOCS · REFACTOR · PERF · CLEAN · REDESIGN · CHORE · STYLE · MERGE (대부분 FEAT·FIX).
- 본문: 한국어. 무엇을 했는지보다 **왜**, 원인이 뭐였는지. `-` 목록 가능. 끝에 검증 한 줄(예: "tsc/lint 클린. 헤드리스로 ○○ 확인.").
- 기능별로 나눠 커밋한다. 관계없는 변경을 한 커밋에 섞지 않는다.
- 여러 줄 메시지는 파일로 써서 `git commit -F <파일>` (PowerShell 에서 `-m` 여러 줄이 깨진다).
- 화면(기능) 하나당 브랜치 하나 — `feat/<화면>`. 다 되면 main 으로 합치고 브랜치는 지운다.
- 푸시는 사용자가 시킬 때만.

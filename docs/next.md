- 이 PC 배치가 끝나면(실패한 곡은 한 번 더) 해석 캐시를 비우고 `npm run eval` — 기존 39개가 42% 근처 이상이면 채택: 브랜치를 main 에 합치고 푸시
- 아니면 옛 프롬프트(가사 찾기 개선은 유지)로 되돌려 다시 쓰고 비교. 한 번 다시 쓰는 데 30~60분(이 PC 망), 수백 원
- **지금 공용 DB 의 곡 설명이 두 형식으로 섞여 있다** — 결론이 날 때까지 배포 추천이 흔들릴 수 있다
- 정한 뒤 볼 것: LLM 재정렬을 순서에 쓸지(`npm run eval -- rerank`), 제목·핵심어 글자 일치 가산(하이브리드)

**cabinet 베타에 와 주셔서 고맙습니다**

지금 기분이나 상황을 편지처럼 적으면, 신의 서류함에서 거기 맞는 노래 10곡을 건져 올려 주는 사이트예요.

👉 https://cabinet-flame-zeta.vercel.app

**이렇게 써 보세요**
1. 서류함 맨 위 서랍에 마우스를 올리면 열려요. 이메일을 넣으면 처음이면 가입(닉네임·비밀번호), 가입했으면 비밀번호만
2. 편지지에 지금 상황을 자유롭게 적고 Enter — "퇴근길 지하철에서 멍하니", "비 오는 밤 혼자 걷는 기분"처럼
3. 디스크를 누르면 30초 미리듣기. 마음에 안 드는 곡은 위로 휙 던지면 빠져요
4. 마음에 들면 "서랍에 넣기" → 공유 카드가 나와요. 링크·QR 로 친구에게 보낼 수 있어요
5. MY CABINET(보관함)에서 서랍을 열면 유튜브로 이어 듣기

**알아 두실 것**
- **PC 크롬**으로 들어와 주세요. 휴대폰 화면은 아직 준비 중이에요(공유 링크 페이지만 휴대폰용)
- 소리를 켜 두면 신이 말을 걸어요(자막도 나와요)
- 비밀번호를 잊으면 첫 화면 오른쪽 위 "열쇠를 잃어버렸나?" → 메일로 재설정 링크가 와요

**무엇을 기록하나요**
- 적은 편지는 곡을 고르려고 Google Gemini 로 보내요. 유료 API 라 Google 이 학습에 쓰지 않아요. 
- 추천을 고치려고 **누가 했는지 모르게** 이런 것만 남겨요: 어떤 편지로 나온 곡을 틀었나·끝까지 들었나, 서랍에 넣었나·공유했나·유튜브로 갔나, 던진 곡, 편지에서 뽑은 분위기 낱말.
  곡을 틀면 그 편지 글이 곡과 함께 남아요(계정·IP 없이). 이름·연락처 같은 건 편지에 적지 말아 주세요
- 방문 수·머문 시간은 Vercel Web Analytics 로 봐요(쿠키 없음)
- **서랍을 공유하면 그 편지 글이 링크를 받은 사람에게 보여요.** 남에게 보이기 싫은 내용은 공유하지 마세요
- 노래 가사 원문은 저장하지 않아요

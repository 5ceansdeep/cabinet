# cabinet

**지금 기분을 편지로 적으면, 신의 서류함에서 어울리는 노래 10곡을 꺼내 드려요.**

▶ https://cabinet-flame-zeta.vercel.app

PC·휴대폰 모두 돼요. (PC 크롬이 가장 매끄러워요)

## 이런 서비스예요

플레이리스트 검색창에 장르나 제목을 넣는 대신, 지금 상황을 그냥 편지처럼 적어 보세요.

> "월요일 아침 출근길, 힘내야 해"
> "친구들이랑 밤 드라이브"
> "일하기 싫을 때 들을 재즈"
> "빈지노 같은 힙합"

편지를 부치면 3D 서류함 방에서 플로피 디스크 10장이 나오고, 신이 한마디 덧붙여 줘요.

## 쓰는 법

1. **들어가기** — 서류함 맨 위 서랍에 마우스를 올리면(휴대폰은 누르면) 열려요. 이메일만 넣으면 처음이면 가입, 아니면 로그인이에요.
2. **편지 쓰기** — 기분, 상황, 듣고 싶은 장르나 가수를 편하게 적고 부쳐요.
3. **듣기** — 디스크를 넘기면 가운데 온 곡의 30초 미리듣기가 바로 나오고, 끝나면 다음 곡으로 이어져요.
4. **고르기** — 별로인 곡은 위로 휙 던지면 빠져요.
   - **던진 곡 채우기**: 뺀 만큼만 새 곡으로
   - **다른 곡으로 다시 찾기**: 10곡을 통째로 새로
5. **좋아요** — 마음에 드는 곡에 하트를 누르면, 다음 추천이 내 취향 쪽으로 조금씩 기울어요.
6. **담기** — "모두 서랍에 넣기"를 누르면 영수증 모양 카드가 인쇄돼 나와요. 사진으로 저장하거나 링크·QR로 공유할 수 있어요.
7. **이어 듣기** — MY CABINET에서 서랍을 열면 유튜브 재생목록으로 끝까지 들을 수 있어요.

## 알아 두세요

- **소리** — 화면을 한 번 눌러야 목소리가 나와요. 아이폰은 무음 모드를 꺼 주세요.
- **비밀번호를 잊었으면** — 첫 화면 오른쪽 위 "비밀번호 찾기"
- **기록** — 편지 글, 나온 곡, 재생·저장·공유 기록은 계정과 무관하게 남아요. 좋아요한 곡만 계정에 남아요(내 추천에 쓰려고).
- **외부 전송** — 편지는 곡을 고르려고 Google Gemini로 보내져요(학습에는 안 쓰여요). 닉네임은 환영 인사 목소리를 만들 때 ElevenLabs로 보내져요.
- **공유** — 서랍을 공유하면 그 편지 글이 링크를 받은 사람에게 보여요.
- 지금은 베타라 데이터가 초기화될 수 있어요.

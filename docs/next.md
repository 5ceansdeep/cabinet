# 다음 할 일 (2026-10-02 기준)

급한 순. 끝낸 항목은 지우고 CONTEXT.md "한 일" 에 한 줄로 옮긴다. [Claude] = Claude 가 하는 일, [사용자] = 직접 해야 하는 일.

## 1. 추천 더 다듬기 [Claude] — 급하진 않다

10/1 정착: 곡 설명·요청 "[핵심어]+묘사" + 재정렬 순서(기존 39개 38%, 전체 45개 41%). 옛 1단계 42%(곡 243개) 수준.
- 배포 주소에서 처음 보는 요청 응답 시간 재기(로컬 4초, 회사망 기준) — 너무 길면 재정렬 후보를 20 → 15 로 표본 평가 후 줄이기
- 제목·핵심어 글자 일치 가산(하이브리드) — 요청 낱말이 제목이나 곡 설명 [핵심어]에 있으면 1단계에서 가산. **표본으로 먼저 잰다**(CLAUDE.md 강한 규칙)
- 평가 세트가 사람이 만든 45개뿐 — 이벤트 기록(4번)이 쌓이면 진짜 평가 세트로

## 2. 공개 전 꼭 할 것

- [사용자] Railway Variables 에 `GMAIL_USER`·`GMAIL_APP_PASSWORD` 확인 → 배포 사이트 `/forgot` 으로 본인 메일 시험 → 그 김에 **관리자 비밀번호 바꾸기**(대화에 노출됨)
- [사용자] AI Studio **비용 제한**(월 한도), **Railway Hobby 전환**(체험 크레딧 30일·$5 끝나기 전)
- [사용자] **`main` 푸시**(10/2 호출 제한·행동 기록·Analytics) → Vercel 프로젝트 **Analytics 탭에서 Enable**
- [사용자] 공유 확인: 서랍에 넣기 → 카드 → 링크를 카톡에 붙여 미리보기 → 휴대폰으로 QR

## 3. 모바일 화면 [Claude] — 큰 작업

공유 링크를 받은 사람은 대부분 휴대폰으로 들어온다. 지금은 PC 전용(세로 화면은 영화 프레임 없이 전체 화면만 해 둠).
- 랜딩: 서랍 호버 → 탭으로 열기, 입력칸 크기
- 결과: 디스크 스와이프, 오른쪽 목록·재생을 아래 시트로, 드라이브 위치
- 보관함: 터치로 서랍 열기·넘기기
- 공개 서랍 `/s/:id` 는 이미 세로 화면 기준

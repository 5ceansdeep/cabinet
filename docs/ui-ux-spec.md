### 폰트

- **Main Sans-Serif**: Inter, Pretendard — 전반적인 UI, 인풋, 데이터 수치. 테크니컬한 무드
- **Concept Serif**: Courier New, Fragment Mono — 아카이빙 보고서, 점수 인쇄, 라벨지. 아날로그 타자기 무드
- **자막**: 조선굴림체, 노란색(`#f3df5f`) + 검정 테두리 + 주황·파랑 색 번짐(글리치), 바탕 없음. 글자를 비트는 효과·필름 입자는 없다(10/6). 크기는 화면 폭을 따라가고 폰은 16px(한 문장이 한 줄에 들게, 10/6)

### 영화 프레임

모든 화면이 영화 비율(2.39:1) 프레임 안. 남는 위아래는 검은 띠, 아래 띠에 자막. 띠는 위아래 각 8% 까지만 —
노트북처럼 높은 화면에선 비율을 조금 양보한다(10/1).

### 일반 UI 규칙 (10/3 디자인 정리 — `.claude/skills/design-rules`)

컨셉 연출(3D·자막·영수증·편지지 등장)은 이 문서의 각 페이지 스펙을 따르고, 버튼·링크·안내·오버레이는 아래를 따른다.

- **버튼 두 가지**(`globals.css`): `.btn` 테두리 버튼, `.btn-solid` 화면의 주 행동 하나. 색은 `--ui` — 흰 화면은 잉크(`#212529`), 검은 방은 시안.
  높이 36px, 고정폭 12px, 자간 .15em, 누르면 98%. 공개 서랍(/s)의 네모 도장 버튼은 영수증 컨셉이라 예외
- **반경**: 버튼·패널·시트·입력·카드 모두 8px(`rounded-ui`) — 알약 모양은 쓰지 않는다(10/3 사용자). 편지지(2px)는 종이라 예외
- **아이콘**: `@phosphor-icons/react` 만, `aria-hidden`. 글리프(▶ ↗ ✕)를 아이콘처럼 쓰지 않는다(영수증 안은 예외)
- **포커스**: 전역 `:focus-visible` 2px 외곽선(`--ui`). `outline-none` 을 쓰면 대신 보이는 표시를 둔다
- **대비**: WCAG AA(본문 4.5:1). UI 글자는 12px 이상, 흐린 글은 불투명도 60% 아래로 내리지 않는다
- **글**: 화면 글에 em-dash(—) 금지 — 쉼표·마침표·콜론. 라벨 구분은 간격으로(`QUERY 편지`)
- **오버레이**(곡 시트·공유 카드): `role="dialog"`, 열면 포커스 이동, Tab 가두기, ESC 닫기, 닫으면 포커스 복귀(`lib/dialog.ts`)
- **모션**: 일반 UI 전환 100~300ms, `transform`·`opacity` 만. 3D 는 `frameloop="demand"` + 움직일 때만 `invalidate`,
  감쇠는 시간 기준(`lib/motion.ts damp`), `useFrame` 안 할당 금지. **움직임 줄이기**(prefers-reduced-motion)면
  덜컹·물결·뒤지기·날아오기·관성·던지기 물리 없이 상태만 바뀐다
- **없는 주소·오류**: `app/not-found.tsx`·`app/error.tsx` — 흰 종이 한 장 + 다시 시도·새 편지 쓰기

### 폰 (10/6)

세로 화면은 영화 프레임 없이 창 전체를 쓴다(자막은 화면 아래에 겹친다). 모양만 다르면 CSS(`portrait:`·`pointer-coarse:`)로,
동작이 달라야 하면 `lib/screen.ts`(`usePortrait`·`useTouch`·`onSwipe`).

- **화각**: 3D 카메라 화각은 세로 기준이라 좁은 화면은 좌우가 잘린다. 화면이 좁으면 화각을 넓혀 주인공(랜딩은 떠오른 서류, 보관함은 서류함)이
  화면 폭의 80% 안에 들게 한다(`dimensions.ts fovFor`, `ArchiveRoom Lens`). DOM 으로 얹는 입력칸·후광도 같은 화각으로 자리를 잡는다
- **호버 대신**: 랜딩 서랍은 누르면 열린다. 결과 화면은 가운데 온 디스크가 들리며 일치도가 찍힌다
- **넘기기**: 3D 위를 민다. 결과·연 서랍은 좌우(디스크), 닫힌 보관함은 위아래(칸). 가로·세로가 뚜렷할 때만 받아 위로 던지기와 안 겹친다.
  손가락으로 끌면 디스크가 돌지 않는다(10/6 — 넘기려다 돌았다). 마우스로 끄는 건 그대로 디스크 돌리기
- **결과 화면**: 맨 위 줄은 왼쪽에 아이콘 두 개(새 편지·내 서랍), 오른쪽에 "서랍에 넣기". 그 아래 요청문을 제목처럼 크게, 해석·조작 안내는 작게(라벨 없음).
  아래는 "PLAYLIST n" 줄(누르면 곡 목록이 펼쳐진다) + 듣는 곡이 있으면 재생 카드(10/6)
- **곡 목록·재생 카드(데스크톱·폰 같음)**: 목록 한 줄 = 작은 표지 + 제목·가수 두 줄, 듣는 곡은 은은한 시안 바탕. 재생 카드 = 둥근 앨범(재생 중이면 디스크처럼 천천히 돈다) + 곡·가수·꺼내기, 진행선, 이전·재생·다음. 듣는 곡은 늘 디스크 줄 가운데로 온다(10/6)
- **자막**: 폰에서도 화면 폭 안에서 어절 단위로 접는다
- **편지**: 편지지를 위쪽에 둔다(키보드에 부치기 버튼이 가리지 않게)
- **입력칸 글자는 16px 이상**(아이폰은 그보다 작은 입력칸으로 화면을 확대한다), 누르는 것은 44px 쯤
- 캔버스는 `touch-action: none` — 끌어도 스크롤·확대·길게 눌러 뜨는 메뉴가 끼어들지 않는다
- 눕힌 폰은 넓은 화면과 같은 배치(프레임이 낮아 빠듯하다 — 쓸 수는 있는 정도)

## 2. 페이지별 스펙

### 1. 랜딩 페이지 (Landing & Auth)

> "끝이 보이지 않는 신의 무한한 백색 공간 (The White Void)"

**시각적 구조**

- 경계선과 끝이 보이지 않는 순백색의 3D 공간
- 화면 전체를 가득 채우는 거대하고 모던한 화이트 3단 서류함(Filing Cabinet) 벽면
- **반응형 레이 캐스팅 그림자**: 마우스 커서 위치가 '빛의 소스'. 커서 이동에 따라 서랍 틈새와 외곽선 그림자 각도가 실시간으로 미세하게 변해 묵직한 입체감을 준다

**인증 UI — 서류함 인풋 호버 체인**

- 초기에는 3단 서류함이 닫혀 있는 구도로 포커싱
- **호버**: 첫 번째 서랍(이메일 단계)에 마우스를 올리면 서랍이 앞으로 15~20도 스르륵 반쯤 열린다. 동시에 서랍 내부에서 은은한 하얀 빛이 새어 나오며 이메일 인풋창이 투명하게 페이드인

**엔터 체인 애니메이션**

1. 첫 번째 서랍 인풋에 이메일 입력 후 Enter
2. 첫 번째 서랍이 "탁" 소리와 함께 단단하게 닫힌다
3. 동시에 두 번째 서랍(비밀번호)이 스르륵 열리며 인풋이 자동 포커싱·활성화
4. 비밀번호 입력 후 Enter → 세 번째 서랍이 열리며 로그인 완료, 다음 로딩 터널로 연계

### 2. 로딩 페이지 (Loading Scene)

> "데이터 아카이브 내부로의 몰입과 다이빙"

**시각적 연속성**

- 랜딩의 화이트 서류함 배경과 마우스 반응형 레이 캐스팅 그림자를 그대로 유지해 끊김 없는 경험

**헤드폰 안내**

- 화면 중앙에 미니멀한 헤드폰 아이콘 + "Please put on your headphones." 텍스트가 부드럽게 페이드 인/아웃

**데이터 스크롤**

- 백엔드가 앨범 이미지·청음 음원 메타데이터를 로딩하는 동안, 화면 한켠에 시스템 로그가 서류 고속 분류되듯 세로로 빠르게 스크롤
- 예시: `[SYSTEM] 구조적 문장 해석 중...` → `[EMBEDDING] 음악 메타데이터 매칭 중...` → `[VECTOR] 768차원 벡터 공간 탐색 중...`

**후광 (Halo)**

- 로딩이 시작되면 열려 있던 서랍이 먼저 "쾅!" 닫힌다
- 그다음 서류함 뒤에서 흰 빛살 후광(흰 핵 + 방사형 빛줄기)이 비치고 주변은 옅은 그림자색으로 가라앉으며, 진행률 따라 화면이 점점 밝아지다 100% 에서 후광이 화면 전체를 하얗게 덮는다
- 하얀 화면 그대로 3번 페이지(흰 테마)로 전환

### 3. 키워드 입력 페이지 (Search Input)

> "신의 서류함 내부 깊은 공간에서 나의 상황을 고하기"

**시각적 구조**

- 후광이 화면을 하얗게 덮은 그 자리 — 순백과 그림자색뿐(따뜻한 색 없음). 신성한 공간에 편지를 쓰는 느낌이지만 "신" 같은 직접적인 단어는 쓰지 않는다
- 화면 중앙에 흰 편지지(명조체)가 떠 있고 "편지 부치기" 로 보낸다

**입력 인터랙션 — 자연어 질의**

- 단순 키워드가 아니라 모호한 상황·감정·시공간을 자유로운 문장으로 입력
- 예: "새벽 2시에 혼자 버스 타고 집에 갈 때 듣고 싶은, 너무 우울하지는 않은 몽환적인 한국 노래"
- **장르 칩(여러 개, 9/30)**: 편지지 아래 11개 — 케이팝·팝·인디·록/밴드·발라드/어쿠스틱·알앤비/소울·힙합·하우스/일렉·재즈·제이팝·샹송.
  안 고르면 가리지 않는다. 고르면 그 장르 곡만(6곡이 안 되면 나머지로 채움), 결과 헤더에 "장르" 줄

**임베딩 시각화 (Vector Particle Effect)**

- 타이핑할 때마다 입력창 주변 배경에 미세한 서류 조각과 빛나는 데이터 입자가 은은하게 일렁이고 흩어진다. AI가 의미 공간을 탐색하는 분위기

### 4 & 4-1. 결과 리스트 도출 & 슬라이드

> "끝없는 서랍 속에서 건져 올린 나만의 음악 디스크"

**결과 도출 연출 (Bruce Almighty Homage)**

- 편지를 부치면 처음부터 3D 서류함 방(검은 로딩 화면 없음, 10/1 — 예전 카드 넘김 화면은 뺐다)
- 곡을 찾는 동안 둘러선 벽의 보이는 서랍들이 여기저기서 탁·탁 빠졌다 닫힌다 — 신이 서류함을 뒤지는 소리("탁")와 함께
- 곡이 오면 정면 한 칸 아래 서랍이 몸통째 쭉 빠지고, 앨범 이미지가 프린팅된 플로피 디스크들이 그 입구에서 차례로 솟아올라 줄을 선다

**플로피 디스크 360도 조작 (Floppy Disk Orbit Control)**

- 양옆 스와이프(Carousel)로 탐색
- **호버**: 디스크가 위로 슬쩍 들리며, 하단 라벨지에 요청과의 일치도가 타자기 스타일로 드르륵 인쇄된다 — `[일치도: 87%]` (분위기 일치도는 2026-09-28 뺌 — 한국 곡은 Last.fm 분위기 태그가 거의 없어 근거 없는 숫자였다)
- **드래그 & 회전**: 디스크를 클릭해 붙잡으면 커서가 `grabbing`으로 변경. 드래그 방향에 따라 3D 공간에서 360도 자유 회전 — 뒷면 플라스틱 마감, 금속 원형 드라이브 허브 등 숨겨진 디테일을 관찰할 수 있다. 놓으면 관성으로 부드럽게 감속하며 정면 구도로 복귀
- **클릭**: 디스크가 화면 아래 드라이브 앞으로 빠르게 와서 눕고(셔터가 안쪽), 진짜 플로피처럼 앞면 입구로 밀려 들어가며 '찰칵' — 미리듣기 재생(10/1).
  드라이브는 화면 아래 끝, 몸통은 어둠에 잠기고 입구만 보인다
- **곡 수·목록(10/1)**: 한 번에 10곡. 오른쪽에 파란 곡 목록(반투명 검은 바탕) — 누르면 그 곡이 드라이브로. 꽂힌 곡은 밝게,
  목록 아래에 재생(동그란 재생 버튼, 얇은 파란 진행선, 꺼내기). 디스크 밑 이름표는 뺐다
- **라벨**: 조명을 안 받는 재질 — 앞에서 비추는 빛에 맨 앞 표지가 하얗게 날아가던 것(10/1)
- **위로 뿌리기 = 제외**: 디스크를 위로 홱 던지면 손을 떠나 포물선으로 날아간다. 중력을 받아 뒤에 선 서류함 벽에 부딪혀 튕기고, 바닥에 떨어져 구르다 멎으면 목록에서 빠진다
- **배경**: 화면 높이만큼 큰 서류함이 시야를 둥글게 감싸고 선다 (CSS 3D 기둥, 위아래는 어둠으로 끝없이)
- **신의 한마디**: 재정렬과 같은 호출로 곡 목록과 함께 온다(10/1). 곡별 이유 한 줄은 화면에 안 보인다(10/1 사용자). 음성은 ElevenLabs 영어(켰을 때) 또는 기계 음성
- **서버 오류(9/30)**: 가짜 곡으로 덮지 않는다 — "서랍이 뻑뻑해서 안 열리네…" + "다시 뒤지기". 가짜 곡은 서버에 아예 닿지 못할 때(개발 중)만

### 5 & 5.1. 아카이빙 및 부속 페이지

> "나만의 비밀 기록 보관소 및 텍스트 데이터 보고서"

**5. 아카이빙 메인 룸 (Personal Cabinet)**

- 건져 올린 곡들을 저장한 개인 전용 서류함 페이지
- 서랍 전면에 연도별 메타 태그나 감정 테마 태그(`#Dreamy`, `#Late-Night`)가 네임택으로 붙어 있다
- 서랍을 클릭하면 앞으로 부드럽게 열리며 카메라가 위로 올라가 안을 내려다본다(Top-down). 모은 플로피 디스크들이 종이 파일 사이에 가지런히 꽂혀 있다. (디스크를 누르면 5.1 보고서로 — 보고서는 2026-09-28 부터 꺼 둠)
- 방(둘러선 서류함 벽)은 4번과 같은 것을 쓴다

**5.1. 상세 부속 페이지 (Document Report)**

- 특정 곡의 디스크나 특정 날짜의 탐험 기록을 뜯어보는 서브 뷰
- 완전히 '아날로그 종이 보고서 서류(Vintage Paper Report)' 기법
- 질감이 느껴지는 빛바랜 종이 배경 위에 아티스트 메타데이터, 사용자가 당시 입력했던 원본 자연어 질의문 배치
- **AI 취향 분석 시각화**: 음악 취향 변화 추이 그래프(Vector 가중치 분석)를 종이 위에 잉크 스탬프로 쾅 찍은 듯한 플랫 그래픽 또는 아날로그 손글씨 서체로 빈티지하게 렌더링
